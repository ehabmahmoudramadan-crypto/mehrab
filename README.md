# مِحراب 🕌

> **لوحة المسلم الذكية** - رفيقك اليومي في رحلتك الروحانية

## ✨ ما هي محراب؟

مِحراب هي تطبيق ويب يجمع كل ما يحتاجه المسلم في مكان واحد - من أوقات الصلاة إلى المصحف التفاعلي، بتصميم عربي جميل وأنيق يHITE_ELEGANT.

## 🌟 المميزات

| الميزة | الوصف |
|--------|-------|
| 📿 **مسبحة رقمية** | عدّاد ذكي مع هدف مخصص وتتبع التقدم |
| 🕌 **أوقات الصلاة** | أوقات دقيقة حسب موقعك مع عد تنازلي |
| 📖 **آية اليوم** | آية عشوائية مع التفسير والترجمة |
| 📖 **المصحف التفاعلي** | تصفح سور القرآن بسهولة مع حفظ الموضع |

## 🛠️ التقنيات

- **HTML5** + **CSS3** + **JavaScript**
- **Tailwind CSS** للتصميم
- واجهة عربية كاملة (RTL)
- تصميم متجاوب يعمل على جميع الأجهزة

## 🚀 التشغيل

```bash
git clone https://github.com/ehabmahmoudramadan-crypto/mehrab.git
cd mehrab
# افتح index.html في المتصفح
```
